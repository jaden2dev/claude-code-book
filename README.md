## 이 책은 어떻게 만들어졌나

이 책은 **하네스 개발법**으로 만들어졌습니다.

```
/harness claude code 입문서를 써줘
```

이 한 줄로 7개의 AI 에이전트가 자동으로 설계되어:

1. **리서치 에이전트** - 공식 문서와 최신 자료 수집
2. **아키텍트 에이전트** - 14챕터 목차 설계
3. **작가 에이전트 x4** - 4개 Part 병렬 동시 집필
4. **어셈블러 에이전트** - 통합, 검수, PDF 변환

에이전트가 에이전트를 만들고, 조립하고, 실행하는 방식입니다.
